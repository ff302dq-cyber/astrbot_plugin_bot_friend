# Bot同类识别器

让 Bot 认识其他 Bot 同类，支持专属提示词、自动识别回复。

## 功能介绍

### 1. 两种对话指令

| 指令格式 | 功能 | 示例 |
|---------|------|------|
| `/tell{名字} {内容}` | LLM 组织语言后回复 | `/tell小饼 她今天真好看` → `-你今天很漂亮` |
| `/forw{名字} {内容}` | 直接转发原话 | `/forw小饼 你是大笨蛋` → `-你是大笨蛋` |

**说明**：
- `{名字}`：目标 Bot 同类的名称（配置的 names 之一）
- `{内容}`：想表达的内容
- 回复会自动加上对方的唤醒词开头（如小饼的唤醒词是 `-`）

### 2. 自动识别回复

当同类名单中的 Bot 发消息时，会自动：
- 识别发送者身份
- 在回复时加上对方的**唤醒词**前缀
- 应用专属提示词和统一回复格式

### 3. 对话轮数控制

- **最大对话轮数**：防止无限循环（默认 6 轮）
- **随机截断**：默认在 4 至 6 轮之间选择本轮总回复数
- 最后一轮会收到自然收束提示并正常发出，后续同类消息不再继续自动回复

### 4. 对话导演

- 专属关系提示词始终优先，导演只负责避免复述、附和和同义反复
- 每轮根据当前原话和最近对话选择一个有依据的轻量推进方式
- 最近保留 4 条对话和 2 个内部动作标签；这些状态只存在内存中
- 动作标签只供代码防重复，发送前会剥离，不会出现在聊天内容中
- 回复正文通常 12 至 30 字，硬上限 40 字，最多两个短句
- 如果上一轮只有简单附和或与近期内容高度重复，下一轮会收到简短纠偏提示

## 配置说明

### Bot 同类配置项

每个同类槽位包含以下配置：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `qq` | 对方 Bot 的 QQ 号 | `123456789` |
| `names` | 名字（多个用英文逗号隔开） | `小饼,烙饼` |
| `wake_prefix` | 对方 Bot 的唤醒词 | `-` |
| `prompt` | 专属提示词 | `小饼是一个活泼可爱的女孩` |

**命令示例**：如果我的唤醒词是 `/`，配置了名字 `小饼`，则可用 `/tell小饼` 或 `/forw小饼`

### 全局配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `reply_format_prompt` | 统一回复格式提示词 | 正文通常 12 至 30 字，最多 40 字 |
| `max_auto_rounds` | 最大自动回复轮数 | `4` |
| `min_auto_rounds` | 随机截断最小轮数 | `1` |

## 使用示例

### 场景 1：让 Bot 组织语言回复

```
用户: /tell小饼 她今天真好看
Bot: -你今天很漂亮
```

### 场景 2：直接转发消息

```
用户: /forw小饼 你是大笨蛋
Bot: -你是大笨蛋
```

### 场景 3：Bot 之间的自动对话

```
Bot一号: -你好
Bot二号: /你好呀
Bot一号: -今天天气真好
Bot二号: /是呢，适合出去玩
```

> 注：自动对话会在随机总轮数后停止，防止无限循环。关系提示词无需为导演功能单独修改。

## 辅助指令

| 指令 | 功能 |
|------|------|
| `/bot同类列表` | 查看已登记的 Bot 同类 |
| `/重置bot对话` | 重置所有群的对话轮数（管理员） |

## 注意事项

1. **唤醒词必须正确填写**，否则对方 Bot 无法识别指令
2. **名字用于指令匹配**，可填写多个别名
3. **不使用 @ 功能**，只用唤醒词即可唤醒对方 Bot
4. 对话轮数限制只对自动回复生效，手动指令不受影响
5. 私聊场景下对话轮数控制不生效
