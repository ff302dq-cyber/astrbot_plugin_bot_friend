# Bot同类识别器

让 Bot 认识其他 Bot 同类，支持专属提示词、自动识别回复。

## 功能介绍

### 1. 两种对话指令

| 指令格式 | 功能 | 示例 |
|---------|------|------|
| `/tell{名字} {内容}` | LLM 组织语言后回复 | `/tell小饼 她今天真好看` → `-你今天很漂亮` |
| `/forw{名字} {内容}` | 直接转发原话 | `/forw小饼 你是大笨蛋` → `-你是大笨蛋` |

**说明**：
- `{名字}`：目标 Bot 同类的名称（配置的 names 之一）
- `{内容}`：想表达的内容
- 回复会自动加上对方的唤醒词开头（如小饼的唤醒词是 `-`）

### 2. 自动识别回复

当同类名单中的 Bot 发消息时，会自动：
- 识别发送者身份
- 在回复时加上对方的**唤醒词**前缀
- 应用专属提示词和统一回复格式

### 3. 对话轮数控制

- **最大对话轮数**：防止无限循环（默认 10 轮）
- **随机截断**：可在最小轮数到最大轮数之间随机截断对话

## 配置说明

### Bot 同类配置项

每个同类槽位包含以下配置：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `qq` | 对方 Bot 的 QQ 号 | `123456789` |
| `names` | 名字（多个用英文逗号隔开） | `小饼,烙饼` |
| `wake_prefix` | 对方 Bot 的唤醒词 | `-` |
| `prompt` | 专属提示词 | `小饼是一个活泼可爱的女孩` |

**命令示例**：如果我的唤醒词是 `/`，配置了名字 `小饼`，则可用 `/tell小饼` 或 `/forw小饼`

### 全局配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `reply_format_prompt` | 统一回复格式提示词 | `你的回复必须自然并严格遵守人物关系。回复严禁超过20字，不得含有任何加粗、格式、emoji、markdown。` |
| `max_auto_rounds` | 最大自动回复轮数 | `10` |
| `min_auto_rounds` | 随机截断最小轮数 | `3` |

## 使用示例

### 场景 1：让 Bot 组织语言回复

```
用户: /tell小饼 她今天真好看
Bot: -你今天很漂亮
```

### 场景 2：直接转发消息

```
用户: /forw小饼 你是大笨蛋
Bot: -你是大笨蛋
```

### 场景 3：Bot 之间的自动对话

```
Bot一号: -你好
Bot二号: /你好呀
Bot一号: -今天天气真好
Bot二号: /是呢，适合出去玩
```

> 注：自动对话会在随机轮数后截断，防止无限循环

## 辅助指令

| 指令 | 功能 |
|------|------|
| `/bot同类列表` | 查看已登记的 Bot 同类 |
| `/重置bot对话` | 重置所有群的对话轮数（管理员） |

## 注意事项

1. **唤醒词必须正确填写**，否则对方 Bot 无法识别指令
2. **名字用于指令匹配**，可填写多个别名
3. **不使用 @ 功能**，只用唤醒词即可唤醒对方 Bot
4. 对话轮数限制只对自动回复生效，手动指令不受影响
5. 私聊场景下对话轮数控制不生效
